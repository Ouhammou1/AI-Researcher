# 🚀 Become Elite AI Researcher

> A complete hands-on roadmap to become an elite AI researcher — from mathematical foundations to deep learning and transformers.

This repository is a **self-study, practice-oriented course** designed to teach Artificial Intelligence and Deep Learning **from first principles**, not only by using libraries but by understanding *how things work under the hood*.

You will progress through:
- Mathematics for Machine Learning  
- PyTorch fundamentals  
- Neural Networks from scratch  
- Optimizers & normalization  
- Advanced topics such as Transformers  

This project is ideal for:
- Students of AI / ML  
- Engineers switching to AI  
- Anyone who wants **deep understanding**, not just copy-paste tutorials
